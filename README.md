# TAU ceramic — демо на нов сайт

Концепция „Изкуството на повърхността“: начална страница и шест продуктови страници за каталог на плочки и обзавеждане за баня. Изработено от WD7 Digital Agency.

## Страници

| Файл | Страница |
|---|---|
| `index.html` | Начална страница |
| `calacatta.html` | Calacatta — гранитогрес с ефект мрамор (цветове Calacatta, Statuario, Crema) |
| `nero.html` | Nero Marquina — ефект черен мрамор |
| `travertino.html` | Travertino — ефект травертин (и Pietra Bianca) |
| `cemento.html` | Cemento — ефект бетон (и Antracite) |
| `rovere.html` | Rovere — ефект дърво, 20 × 120 (и Noce) |
| `terrazzo.html` | Terrazzo — декоративна плочка |

## Структура

Всички файлове са в една папка, без подпапки — така се качват лесно и през браузъра:

- `*.html` — страниците
- `runtime.js` — малък скрипт, който рисува шаблоните и управлява интерактивността
- `*.jpg`, `*.svg` — текстури, 3D чертеж и иконка

Сайтът е статичен — няма сървър, база данни или build стъпка. Работи директно от GitHub Pages.

## Публикуване в GitHub Pages

1. Създайте ново хранилище в GitHub и качете **всички** файлове от тази папка в корена му (Add file → Upload files → маркирайте всички файлове с Ctrl+A и ги провлачете).
2. Отворете **Settings → Pages**.
3. В **Build and deployment → Source** изберете **Deploy from a branch**.
4. Изберете клон `main` и папка `/ (root)`, натиснете **Save**.
5. След около минута сайтът е достъпен на `https://<потребител>.github.io/<хранилище>/`.

## Локален преглед

Отворете папката в терминал и стартирайте:

```
python3 -m http.server 8000
```

След това отворете `http://localhost:8000`.

## Бележки

- Снимките и имената на продуктите са примерни.
- Полетата в квадратни скоби (`[ЦЕНА]`, `[КОД]`, `[ТЕЛЕФОН]` и др.) се попълват с реални данни.
- Шрифтовете се зареждат от Google Fonts.
